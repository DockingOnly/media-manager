Media Manager — test build
==========================

Starting it
  1. Unzip the whole folder somewhere you can write to (for example Documents\MediaManager). Keep the files together.
  2. Double-click MediaManager.exe. A small black window opens, then the app opens in your browser at
     http://127.0.0.1:8765. Closing the browser tab shuts the app down (or close the black window).
  3. Windows may say "Windows protected your PC" because this test build isn't signed. Choose
     "More info", then "Run anyway".

First run
  - Enter your movie (or TV) folder and choose Scan folder. Nothing on disk changes until you choose an action
    such as Rename or Write .nfo files, and every change can be undone from History & undo.
  - Open Settings (bottom of the sidebar) and add a free TMDB API key to match your movies.
  - API keys are kept in Windows Credential Manager, never in a plain file.

Where your data lives
  Settings, scans, matches, history, backups and logs: %LOCALAPPDATA%\Media Manager
  (paste that into the File Explorer address bar). Deleting the app folder leaves them; delete that folder too
  to remove everything.

The two views
  Technical (table and toolbar) and Theatrical (posters and shelves). Switch at the top, or press V.
  Press ? in the app for every keyboard shortcut.

If something goes wrong
  Tools (the ... button) > Open the log file, and send it along with what you did.

For trying it without touching an existing setup
  Start it from a Command Prompt with these set first:
    set MM_DATA=%TEMP%\mm-trial        (an empty folder for its data)
    set MM_PORT=8790                   (run next to a copy that's already open)
    set MM_ISOLATED=1                  (no Credential Manager, backups, log file or notifications)
    MediaManager.exe
